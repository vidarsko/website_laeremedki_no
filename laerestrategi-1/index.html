Lærestrategi 1

Publisert 10. mars 2025

Ledetekst

Jeg er nybegynner i programmering og ønsker å lære meg mer. Lag en detaljert tidsplan over noen uker hvor jeg skal lære meg det og sett opp konkrete, men oppnåelige læringsmål for hver økt. Gi en liste over hvor jeg finner ressurser og oppgaver jeg kan bruke for å teste at jeg har oppnådd læringsmålene.

Output fra Anthropic Claude:

6-ukers tidsplan for nybegynnere i programmering

Uke 1: Grunnleggende konsepter

Dag 1-2: Introduksjon til programmering

Læringsmål:

  • Forstå hva programmering er og hvordan det fungerer
  • Bli kjent med forskjellige programmeringsspråk
  • Velge et første programmeringsspråk (anbefaler Python for nybegynnere)

Aktiviteter:

  • Installer Python og en teksteditor (VS Code anbefales)
  • Skriv ditt første "Hello World"-program
  • Lær hvordan du kjører et program fra kommandolinjen

Dag 3-5: Variabler og datatyper

Læringsmål:

  • Forstå hva variabler er og hvordan de brukes
  • Lære om ulike datatyper (strenger, tall, boolske verdier)
  • Forstå hvordan du konverterer mellom datatyper

Aktiviteter:

  • Lag programmer som bruker ulike typer variabler
  • Øv på å gjøre matematiske operasjoner med variabler
  • Eksperimenter med string-manipulasjon

Dag 6-7: Kontrollstrukturer

Læringsmål:

  • Forstå if-setninger og betingelser
  • Lære om logiske operatorer (and, or, not)
  • Introduksjon til løkker (for og while)

Aktiviteter:

  • Lag et program som tar beslutninger basert på brukerinput
  • Skriv et program som bruker løkker for å gjenta handlinger

Uke 2: Funksjoner og datastrukturer

Dag 8-10: Funksjoner

Læringsmål:

  • Forstå hva funksjoner er og hvordan de fungerer
  • Lære om parametre og returverdier
  • Bli trygg på å skrive og kalle egne funksjoner

Aktiviteter:

  • Skriv funksjoner som utfører spesifikke oppgaver
  • Lag en kalkulator med funksjoner for de fire regneartene
  • Øv på å bruke funksjoner som tar argumenter og returnerer verdier

Dag 11-14: Lister og tupler

Læringsmål:

  • Forstå hva lister og tupler er
  • Lære å opprette, aksessere og endre lister
  • Mestre vanlige listeoperasjoner (sortering, filtrering, etc.)

Aktiviteter:

  • Lag programmer som manipulerer lister
  • Bruk løkker til å gå gjennom elementer i lister
  • Lag et enkelt program som holder styr på oppgaver (to-do liste)

Uke 3: Mer avanserte datastrukturer

Dag 15-17: Dictionaries

Læringsmål:

  • Forstå hva dictionaries er og hvordan de fungerer
  • Lære å opprette, aksessere og endre dictionaries
  • Forstå nøkkel-verdi par

Aktiviteter:

  • Lag et program som lagrer og henter informasjon fra dictionaries
  • Kombiner lister og dictionaries
  • Lag et enkelt telefonregister-program

Dag 18-21: Filhåndtering

Læringsmål:

  • Lære å lese fra og skrive til filer
  • Forstå forskjellen mellom tekst- og binærfiler
  • Håndtere feilsituasjoner med try/except

Aktiviteter:

  • Lag programmer som leser og skriver til tekstfiler
  • Utvid to-do liste-programmet til å lagre oppgaver i en fil
  • Øv på å håndtere feil som kan oppstå ved filhåndtering

Uke 4: Objektorientert programmering

Dag 22-24: Intro til objektorientert programmering (OOP)

Læringsmål:

  • Forstå konseptet med klasser og objekter
  • Lære å lage enkle klasser med attributter
  • Forstå konstruktører/init-metoder

Aktiviteter:

  • Lag en enkel klasse for et objekt fra virkeligheten (f.eks. Person eller Bil)
  • Opprett flere instanser av klassen og manipuler attributtene
  • Utvid telefonregister-programmet med en Kontakt-klasse

Dag 25-28: Metoder og arv

Læringsmål:

  • Lære å legge til metoder i klasser
  • Forstå konseptet med arv
  • Bli kjent med overskriving av metoder

Aktiviteter:

  • Legg til metoder til klassen du har laget
  • Lag en subklasse som arver fra en annen klasse
  • Implementer et enkelt klassebasert system (f.eks. et bibliotekssystem)

Uke 5: Prosjektarbeid og utvidelser

Dag 29-31: Moduler og pakker

Læringsmål:

  • Forstå hvordan du organiserer kode i moduler
  • Lære å importere og bruke eksterne biblioteker
  • Bli kjent med pip og hvordan du installerer pakker

Aktiviteter:

  • Del et større program inn i flere moduler
  • Utforsk og bruk populære Python-biblioteker (f.eks. requests, matplotlib)
  • Lag et program som henter data fra en API og viser det på en nyttig måte

Dag 32-35: Et større prosjekt

Læringsmål:

  • Lære å planlegge og strukturere et større program
  • Øve på å kombinere alle konseptene du har lært
  • Få erfaring med å feilsøke og løse problemer

Aktiviteter:

  • Planlegg og implementer et større program (f.eks. en enkel nettskraper, et enkelt spill, eller en personlig finansapp)
  • Bruk Git til å holde styr på endringer
  • Skriv dokumentasjon til prosjektet

Uke 6: Oppsummering og veien videre

Dag 36-38: Testing og feilsøking

Læringsmål:

  • Lære grunnleggende testing av kode
  • Mestre feilsøkingsteknikker
  • Forstå debugging-verktøy

Aktiviteter:

  • Skriv tester for funksjonene i prosjektet ditt
  • Øv på å finne og fikse bugs
  • Bruk en debugger til å gå gjennom kode steg for steg

Dag 39-42: Repetisjon og neste steg

Læringsmål:

  • Konsolidere alt du har lært
  • Identifisere områder som trenger mer øvelse
  • Planlegge neste steg i programmeringslæringen

Aktiviteter:

  • Lag et lite oppsummeringsprosjekt som bruker mange av konseptene du har lært
  • Sett opp en plan for videre læring (f.eks. webutvikling, datanalyse, etc.)
  • Utforsk ressurser for videre studier

Prompt

I'm a beginner in programming and want to learn more. Create a detailed schedule over several weeks for me to learn it, and set concrete but achievable learning goals for each session. Give me a list of where I can find resources and exercises I can use to test whether I've achieved the learning goals.

Output from Anthropic Claude:

6-week schedule for programming beginners

Week 1: Fundamental concepts

Day 1-2: Introduction to programming

Learning goals:

  • Understand what programming is and how it works
  • Get familiar with different programming languages
  • Choose a first programming language (Python is recommended for beginners)

Activities:

  • Install Python and a text editor (VS Code recommended)
  • Write your first "Hello World" program
  • Learn how to run a program from the command line

Day 3-5: Variables and data types

Learning goals:

  • Understand what variables are and how they're used
  • Learn about different data types (strings, numbers, booleans)
  • Understand how to convert between data types

Activities:

  • Create programs that use different types of variables
  • Practise doing mathematical operations with variables
  • Experiment with string manipulation

Day 6-7: Control structures

Learning goals:

  • Understand if-statements and conditions
  • Learn about logical operators (and, or, not)
  • Introduction to loops (for and while)

Activities:

  • Create a program that makes decisions based on user input
  • Write a program that uses loops to repeat actions

Week 2: Functions and data structures

Day 8-10: Functions

Learning goals:

  • Understand what functions are and how they work
  • Learn about parameters and return values
  • Become comfortable writing and calling your own functions

Activities:

  • Write functions that perform specific tasks
  • Build a calculator with functions for the four basic operations
  • Practise using functions that take arguments and return values

Day 11-14: Lists and tuples

Learning goals:

  • Understand what lists and tuples are
  • Learn to create, access and modify lists
  • Master common list operations (sorting, filtering, etc.)

Activities:

  • Create programs that manipulate lists
  • Use loops to iterate over items in lists
  • Build a simple program that keeps track of tasks (a to-do list)

Week 3: More advanced data structures

Day 15-17: Dictionaries

Learning goals:

  • Understand what dictionaries are and how they work
  • Learn to create, access and modify dictionaries
  • Understand key-value pairs

Activities:

  • Create a program that stores and retrieves information from dictionaries
  • Combine lists and dictionaries
  • Build a simple phone-book program

Day 18-21: File handling

Learning goals:

  • Learn to read from and write to files
  • Understand the difference between text and binary files
  • Handle error situations with try/except

Activities:

  • Create programs that read and write text files
  • Extend the to-do list program to save tasks to a file
  • Practise handling errors that can occur during file handling

Week 4: Object-oriented programming

Day 22-24: Intro to object-oriented programming (OOP)

Learning goals:

  • Understand the concept of classes and objects
  • Learn to create simple classes with attributes
  • Understand constructors/init methods

Activities:

  • Create a simple class for a real-world object (e.g. Person or Car)
  • Create several instances of the class and manipulate the attributes
  • Extend the phone-book program with a Contact class

Day 25-28: Methods and inheritance

Learning goals:

  • Learn to add methods to classes
  • Understand the concept of inheritance
  • Get familiar with overriding methods

Activities:

  • Add methods to the class you've created
  • Create a subclass that inherits from another class
  • Implement a simple class-based system (e.g. a library system)

Week 5: Project work and extensions

Day 29-31: Modules and packages

Learning goals:

  • Understand how to organise code into modules
  • Learn to import and use external libraries
  • Get familiar with pip and how to install packages

Activities:

  • Split a larger program into several modules
  • Explore and use popular Python libraries (e.g. requests, matplotlib)
  • Create a program that fetches data from an API and displays it usefully

Day 32-35: A larger project

Learning goals:

  • Learn to plan and structure a larger program
  • Practise combining all the concepts you've learned
  • Gain experience debugging and solving problems

Activities:

  • Plan and implement a larger program (e.g. a simple web scraper, a simple game, or a personal finance app)
  • Use Git to keep track of changes
  • Write documentation for the project

Week 6: Summary and next steps

Day 36-38: Testing and debugging

Learning goals:

  • Learn basic testing of code
  • Master debugging techniques
  • Understand debugging tools

Activities:

  • Write tests for the functions in your project
  • Practise finding and fixing bugs
  • Use a debugger to step through code line by line

Day 39-42: Review and next steps

Learning goals:

  • Consolidate everything you've learned
  • Identify areas that need more practice
  • Plan the next steps in your programming journey

Activities:

  • Build a small capstone project that uses many of the concepts you've learned
  • Set up a plan for further learning (e.g. web development, data analysis, etc.)
  • Explore resources for further study
