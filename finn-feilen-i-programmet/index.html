Finn feilen i programmet

Publisert 10. april 2025

Få KI til å lage et program også introdusere en feil i programmet. Ha dette programmet på en powerpoint og la elevene prøve å finne feilen.

Ledetekst

Lag et veldig enkelt python-program som inneholder en feil.

Varianter

  • Be KI-en om å legge inn en feil som er faglig.

Ledetekst

Lag et veldig enkelt python-program fra faget [FAG] som inneholder en faglig feil.

Have AI create a program and introduce a bug into it. Put the program on a slide and let the students try to find the bug.

Prompt

Create a very simple Python program that contains a bug.

Variations

  • Ask the AI to introduce a bug that is subject-related.

Prompt

Create a very simple Python program from the subject [SUBJECT] that contains a subject-related error.
