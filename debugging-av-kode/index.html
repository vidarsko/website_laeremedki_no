Debugging av kode

Publisert 19. desember 2024

Triks for å bruke KI til å finne feil i koden din når den ikke gjør som den skal.

Lim inn feilmeldingen

Feilmeldinger kan være kryptiske. Ved å lime de inn i en språkmodell kan du få forklart feilene i klarspråk.

I get this error:
"""
Traceback (most recent call last):
  File packages\cupy\fft\_fft.py", line 785, in fftn
    from cupy.cuda import cufft
ImportError: DLL load failed while importing cufft: The specified module could not be found.
"""
Can you tell me what is wrong and suggest some alternatives for how to fix it?

Svar:

Be den bruke enklere funksjoner

Når du bruker språkmodeller til å skrive kode, hender det at den bruker funksjoner og teknikker som er langt mer avanserte enn du forstår og ønsker. Be den derfor holde seg unna ulike typer funksjoner og pakker.

Jeg ønsker at du kun bruker numpy i dette programmet.
Jeg forstår ikke hva disse "def"-kommandoene betyr. Kan du skrive et nytt program hvor du ikke bruker disse?

Tricks for using AI to find bugs in your code when it isn't doing what it's supposed to.

Paste in the error message

Error messages can be cryptic. By pasting them into a language model, you can get the errors explained in plain language.

I get this error:
"""
Traceback (most recent call last):
  File packages\cupy\fft\_fft.py", line 785, in fftn
    from cupy.cuda import cufft
ImportError: DLL load failed while importing cufft: The specified module could not be found.
"""
Can you tell me what is wrong and suggest some alternatives for how to fix it?

Answer:

Ask it to use simpler functions

When you use language models to write code, it sometimes uses functions and techniques that are far more advanced than you understand or want. So ask it to avoid certain kinds of functions and packages.

I want you to only use numpy in this program.
I don't understand what these "def" commands mean. Can you write a new program where you don't use them?
