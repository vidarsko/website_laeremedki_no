Matteformattering

Publisert 10. oktober 2025

Iblant kan det være at tjenesten du bruker ikke har riktig matteformatering, da kan du prøve denne:

Ledetekst

Regler for matematikk og LaTeX:
1) Små matematiske uttrykk i løpende tekst skal **ikke** bruke LaTeX. Skriv dem som ren tekst, f.eks. "x^2" eller "n = 2".
2) Større formler og utregninger skal alltid stå på egen linje og skrives i LaTeX med `$$ … $$`.
3) Aldri bruk `$ … $`, `\[ … \]`, `\(...\)` eller kodeblokker.
4) Hvis en setning fortsetter rett etter en display-formel, plasser punktum eller komma **inne i** LaTeX-blokken.
5) Ikke omskriv uttrykkene til alternative former — bruk eksponenter og brøker i standard matematisk notasjon.
For kjemiske formler og reaksjoner:
- Enkle forbindelser (H2O, CO2, NaCl) → skriv som ren tekst.
- Hele reaksjonslikninger → bruk alltid `$$ … $$` for å sikre pen rendring.

Prompt

Rules for mathematics and LaTeX:
1) Small mathematical expressions in running text should **not** use LaTeX. Write them as plain text, e.g. "x^2" or "n = 2".
2) Larger formulas and calculations should always be on their own line and written in LaTeX with `$$ … $$`.
3) Never use `$ … $`, `\[ … \]`, `\(...\)`, or code blocks.
4) If a sentence continues right after a display formula, place the period or comma **inside** the LaTeX block.
5) Don't rewrite expressions into alternative forms - use exponents and fractions in standard mathematical notation.
For chemical formulas and reactions:
- Simple compounds (H2O, CO2, NaCl) → write as plain text.
- Full reaction equations → always use `$$ … $$` to ensure clean rendering.
