Program-puslespill

Publisert 10. april 2025

Lær elevene programmering gjennom å pusle sammen biter. Du kan generere et program som elevene skal pusle ved hjelp av KI, f.eks. gjennom å bruke denne ledeteksten.

Ledetekst

Lag tre pythonprogrammer i stigende vanskelighetsgrad fra veldig enkelt til litt komplisert. Hensikten med programmene er at de skal klippes opp og deles ut til elever som skal forsøke å klippe dem sammen. La det derfor være litt mellomrom mellom linjene. Unngå også for mange funksjonskall. I det enkle tilfellet kan koden inneholde litt dokumentasjon.

Bruk temaet [TEMA] fra [FAG] som inspirasjon for oppgavene.

Jeg brukte temaet geometri fra matematikk:

Ofte er det ikke bare én måte å løse oppgaven på.

Varianter

  • La elevene kjøre programmet etter å puslet det sammen

Eksempel

Dette eksempelet var opprinnelig et interaktivt dra-og-slipp-verktøy (bygget med Tailwind CSS og Sortable.js) hvor man kunne lime inn kode og øve på å sette linjene i riktig rekkefølge. Verktøyet lot seg ikke gjenskape som en statisk side her, men viser godt hva KI kan generere av interaktive læringsverktøy på egen hånd.

Teach your students programming by having them piece code back together. You can generate a program for the students to reassemble using AI, for example with this prompt.

Prompt

Create three Python programs of increasing difficulty, from very simple to somewhat complex. The purpose of the programs is that they will be cut into pieces and handed out to students, who will try to piece them back together. Leave some space between the lines to make this possible. Also avoid too many function calls. In the simple case, the code can include some documentation.

Use the theme [TOPIC] from [SUBJECT] as inspiration for the tasks.

I used the theme of geometry from mathematics:

Often there's more than one way to solve the task.

Variations

  • Let the students run the program after piecing it together

Example

This example was originally an interactive drag-and-drop tool (built with Tailwind CSS and Sortable.js) where you could paste in code and practice putting the lines back in the right order. The tool couldn't be recreated as a static page here, but it's a good illustration of the kind of interactive learning tools AI can generate on its own.
