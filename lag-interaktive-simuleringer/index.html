Her lønner det seg å bruke en god språkmodell, da de enkleste ikke er så gode på å kode sammensatte objekter. GPT 5 pleier å gjøre det godt, Gemini pro også. I noen KI-tjenester, slik som Google Gemini Pro, kan du også kjøre html-simuleringen direkte i "canvas" mode, slik det ser ut under.

Dersom du ikke har google gemini, kan du allikevel lage og kjøre dine egne simuleringer. Slik gjør du det:

1. Generer koden

For å lage en slik, bruk en språkmodell og lim inn instruksen under, etterfulgt av en beskrivelse for hva du vil simulere.

Instruks

Lag en interaktiv simulering i html for å hjelpe å forstå et tema. Simuleringen skal ha elementer som brukeren kan endre på, f.eks. glidere eller knapper.
[SKRIV INN HVA DU ØNSKER Å LAGE EN SIMULERING OM].

2. Kopier koden og lim den inn i et teksbehandlingsprogram, f.eks. notepad

3. Lagre som en html-fil

4. Dobbeltklikk på filen for å åpne i f.eks. edge

(Du kan prøve denne nedarvingssimulatoren på skolesim.no).

The demo above is a live simulation whose interface text is in Norwegian, since it was originally generated for a Norwegian classroom — kept as-is rather than rebuilt in English, since it's meant as a demonstration of what the AI produced, not a template to translate.

Here it pays off to use a good language model, since the simplest ones aren't very good at coding composite objects. GPT-5 tends to do well, Gemini Pro too. In some AI services, such as Google Gemini Pro, you can also run the html simulation directly in "canvas" mode, as shown below.

If you don't have Google Gemini, you can still create and run your own simulations. Here's how:

1. Generate the code

To make one, use a language model and paste in the prompt below, followed by a description of what you want to simulate.

Prompt

Create an interactive simulation in HTML to help explain a topic. The simulation should have elements the user can change, e.g. sliders or buttons.
[DESCRIBE WHAT YOU WANT TO SIMULATE].

2. Copy the code and paste it into a text editor, e.g. Notepad

3. Save it as an html file

4. Double-click the file to open it in, e.g., Edge

(You can try this inheritance simulator on skolesim.no).
