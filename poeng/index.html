Poengoversikt

Publisert 2. desember 2025

En interaktiv oversikt som sammenligner poengsummer fra menneske-rettede og KI-rettede prøver, hentet direkte fra et regneark. Bruk kontrollene under grafen til å filtrere på dato, velge hvilken oppgave som vises, og slå av/på visning av snitt og standardavvik.

An interactive overview comparing scores from human-graded and AI-graded tests, pulled directly from a spreadsheet. Use the controls below the chart to filter by date, choose which task is shown, and toggle the mean/standard-deviation display.

The embedded tool below has a Norwegian interface (labels like "Mennesker"/"KI", date filter, etc.), since it was built for a Norwegian classroom dataset — kept as-is rather than rebuilt in English, since translating the tool itself is a separate task from translating this article.
