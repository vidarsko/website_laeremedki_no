Lage HTML-simuleringer

Publisert 9. januar 2026

Mange faglige begreper, særlig i realfag, kan være vanskelige for elever å visualisere og forstå kun gjennom statiske bilder eller tekst.

For å løse dette kan du bruke en KI-tjeneste til å generere interaktive HTML-simuleringer som elevene kan utforske direkte i en vanlig nettleser. Start med å identifisere et konsept som krever visualisering, for eksempel elektrisitet, bølger eller kjemiske reaksjoner. Formuler en presis instruks til KI-en der du beskriver nøyaktig hva simuleringen skal inneholde; be gjerne om spesifikke elementer som glidere (sliders) for å endre variabler, knapper for å starte animasjoner eller tekstfelt for målinger. Dersom det første resultatet ikke er tilfredsstillende, bruker du KI-en som en samtalepartner for å feilsøke, legge til flere funksjoner eller pynte på designet. Når koden er ferdig, kopierer du den inn i en enkel tekstfil, lagrer den med filendelsen .html, og deler filen med elevene via din vanlige læringsplattform. Elevene kan da bruke simuleringen som et verktøy for utforskning, enten som en introduksjon til et tema eller som støtte under praktisk lab-arbeid og beregningsoppgaver.

Du finner mange simuleringer på skolesim.no.

Under kan du høre Sondre sin erfaring med dette.

Many academic concepts, especially in the sciences, can be difficult for students to visualize and understand through static images or text alone.

To address this, you can use an AI service to generate interactive HTML simulations that students can explore directly in an ordinary web browser. Start by identifying a concept that requires visualization, for example electricity, waves, or chemical reactions. Formulate a precise instruction to the AI describing exactly what the simulation should contain; feel free to ask for specific elements such as sliders to change variables, buttons to start animations, or text fields for measurements. If the first result isn't satisfactory, use the AI as a conversation partner to debug, add more features, or polish the design. Once the code is ready, copy it into a plain text file, save it with the .html file extension, and share the file with students via your usual learning platform. Students can then use the simulation as a tool for exploration, either as an introduction to a topic or as support during practical lab work and calculation tasks.

You'll find many simulations at skolesim.no.
